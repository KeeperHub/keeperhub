## Goal

Make listed workflows discoverable across the platform, modernize Hub UX so logged-out users can browse, consolidate workflow import/export into one modal, and let template adoption flow through a clear login-gated CTA.

- **Phase 42 — Foundations & Shared Primitives:** Single `WorkflowIOOverlay` (Radix Tabs) replaces split import/export overlays; shared `SignInPromptOverlay` + `useAuthPrompt` hook; logged-out left-nav with `requireAuth: boolean` per item + `useSession().isPending` first-paint skeleton + `usePersistedNavState` versioning; import schema hardened (`.passthrough()` -> `.strict()`, `.max()` caps on free-text, https-only webhook URLs, `Content-Length` 413 guard, code-step gate). 9/10 plans complete; Plan 42-10 manual UAT pending interactive run (status: human_needed; downstream Phase 43+44 verification provides implicit pass).
- **Phase 43 — Hub UX Overhaul:** Green "Use template" CTA with full-tile click overlay; anonymous + auto-anonymous Use-template OAuth round-trip via `pending_template` HttpOnly cookie + `PendingTemplateRunner` (NO localStorage); deep-link `/hub/tags/[tag]` route with `generateStaticParams` + tag-specific `generateMetadata` + sitemap enumeration + reserved-slug validator (`tags`, `protocol`, `marketplace`, `auth`, `api`, `admin`, `_next`, `og`, `well-known`); Cards/List view toggle persisted in `hub_view` cookie (server-readable, NO localStorage, zero hydration mismatch); Sort+Tags moved into the left sidebar; sidebar tag-link clicks wrapped in `useTransition` + `router.push` with scroll preservation. UAT complete 2026-05-01, 15/15 passed across 14 plans.
- **Phase 44 — Unified Tabbed Hub:** `/hub` is now a tabbed shell with three tabs (Protocols default / Workflows / Marketplace) using Radix Tabs via the existing shadcn wrapper. URL contract is `?tab=` query param updated via `router.replace(url, { scroll: false })`. Hero rewritten to "Hub" + "Browse protocols, fork community workflows, and discover paid services on the marketplace." (`components/hub/hub-hero.tsx`). Protocols tab is a full-card responsive grid (`ProtocolCardV2`); Workflows tab lifts the Phase-43 view-shell body unchanged; Marketplace tab is a server component running a Drizzle GROUP-BY join over `workflows ⋈ workflow_payments` wrapped in `unstable_cache(300s)` with cursor pagination LIMIT 50 and a privacy-whitelisted SELECT (zero leaks of `creatorWalletAddress`, `userId`, `organizationId`, `payerAddress`, `amountUsdc`). Sort dropdown shows Popular (default) + Newest only; earnings sort EXPLICITLY ABSENT. Single "Hub" left-nav entry; no secondary Marketplace link. MCP API extended: `GET /api/mcp/workflows?sort=popular|recent` and `search_workflows` MCP tool gain matching `sort` param; tool count unchanged. Composite `(workflow_id, settled_at)` index reviewed via EXPLAIN ANALYZE and intentionally NOT added (existing `idx_workflow_payments_workflow` covers the GROUP-BY plan). Per-tab `generateMetadata` returns per-tab title + description + OG image. UAT GREEN; live cross-browser sweep verified in real Chrome via `claude-in-chrome` MCP (FF/Safari deferred per user accept). 24 commits across 12 plans.
- **Phase 45 — Back/Forward Hydration Fix:** Root-layout dev-only `<Script>` (`app/layout.tsx`, commit `06c1867f`) supersedes the per-page Phase-43 workaround on `app/hub/layout.tsx` (commit `cef214f0`, deleted via commit `d4e61a36`).
